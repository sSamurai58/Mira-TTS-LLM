# Rules

## Что делать и чего избегать

- Один путь выпуска из `docs/PRD.md`; не раздувать v1 до DAW, видео или SaaS.
- Имена экранов, сущностей и ошибок — только из `docs/GLOSSARY.md`.
- Секреты, ключи API и веса чужих моделей не коммитить в репозиторий.
- Голосовая модель — именованный артефакт с импортом/экспортом; не «просто папка файлов без контракта».

## Библиотеки

- Выбор стека фиксируется ADR в `docs/DECISIONS.md` после бэкенда/DevOps.

## Обработка ошибок

- Ошибки обучения, нарезки, TTS и API именуются в `docs/GLOSSARY.md` и контракте бэкенда.

## Ограничения по коду

- Production только после вердикта тестировщика и заполненного `docs/RELEASE.md`.
