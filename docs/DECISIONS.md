# Decisions (ADR)

## ADR-1: Фокус v1 на Studio Path (TTS + LLM + свой голос)
- Дата: 2026-11-15
- Статус: принято
- Контекст: Запрос пользователя покрывает текст, запись, нарезку, обучение голоса, импорт/экспорт и подключение к другим проектам — объём легко расползается в DAW/SaaS.
- Решение: Первый выпуск — один путь Studio Path; DAW, видео, маркетплейс и мобильное — снаружи.
- Альтернативы: Сразу полноценная студия с монтажом; только API без UI; только чужой TTS без своей модели.
- Последствия: Дизайн и контракт строятся вокруг датасета, сегментов, модели, jobs и локального API.

## ADR-2: Поверхность v1 — desktop
- Дата: 2026-11-15
- Статус: принято
- Контекст: Нужна первая оболочка для Studio Path; кандидат — desktop или локальный веб.
- Решение: Локальное desktop-приложение как единственная поверхность v1.
- Альтернативы: Веб-сервис у себя на машине; сразу обе оболочки.
- Последствия: Дизайн — window shell + шаг-навигатор; стек UI/рантайма выбирает бэкенд/фронтенд под desktop; мобильное и браузерный SaaS остаются снаружи.
