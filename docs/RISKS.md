# Risks

## Открытые
- Обучение голосовых моделей требует GPU/времени — влияние на UX и DevOps — зафиксировать минимальные требования после бэкенда — бэкенд/DevOps
- Качество автонарезки на шумных записях — ломает датасет — специалист предмета + пороги в контракте — domain/backend
- Desktop toolkit ещё не выбран — риск смены стека UI — ADR после контракта — бэкенд/фронтенд

## Снятые
- Расползание в DAW/SaaS в v1 — 2026-11-15 — ADR-1 и списки «снаружи» в `docs/PRD.md`
- Поверхность v1 не выбрана — 2026-11-15 — ответ пользователя «desktop», ADR-2
