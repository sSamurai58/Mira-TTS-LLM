# Domain — речь и голосовой датасет (Mira v1)

```text
Область: Синтез речи / подготовка голосового датасета для TTS (запись, сегментация, обучение голоса).
Граница суждения:
  - Могу подтвердить инженерные пределы датасета: формат, длительность, единицы времени, минимальный объём для старта обучения, запрет обещать биометрическую «личность» или юридическую чистоту чужого голоса.
  - Не подтверждаю клиническую оценку слуха, судебную идентификацию диктора, лицензионный статус конкретного чужого аудио — для этого нужен практикующий специалист / юрист правообладателя.
Словарь:
  - семпл (VoiceSample) — один непрерывный аудиофайл голоса в датасете — путают с «сэмпл музыки» / MIDI
  - сегмент (Segment) — вырезанный кусок речи с границами startMs–endMs — путают с главой сценария
  - слово (kind=word) — короткий сегмент одной лексической единицы; в v1 операционно: длительность 80–800 ms — путают с орфографическим «словом» без аудиограниц
  - фраза (kind=phrase) — сегмент из нескольких слов или цельного высказывания; в v1: длительность 400–15000 ms — путают с абзацем текста
  - голосовая модель (VoiceModel) — артефакт синтеза «похож на этот датасет» — путают с биометрическим слепком личности / proof of identity
  - нарезка — автоматическое предложение границ сегментов — путают с финальной разметкой (финал = accepted человеком)
  - озвучка (TTS / AudioRender) — синтез по тексту выбранной моделью — путают с записью живого микрофона
  - LLM-текст — черновик ScriptText — путают с гарантированно верной транскрипцией семпла
Правила:
  - Импорт/запись только wav или flac, PCM; mp3/aac отвергать — следствие SampleFormatUnsupported — единица: контейнер/кодек — предел: только wav|flac
  - Для wav: sampleRate ∈ {16000, 22050, 24000, 44100, 48000} Hz, mono предпочтительно; >2 каналов отвергать — SampleChannelsUnsupported — Hz / каналы — предел: 1–2 канала; при 2 каналах продукт сводит в mono при импорте или предупреждает (v1: отвергать >2, 2 канала принимать с пометкой downmix в логе воркера)
  - Длительность VoiceSample — следствие при нарушении SampleDurationInvalid — единица ms — предел: минимум 500 ms, максимум 300000 ms (5 мин) на один семпл в v1
  - Сегмент: startMs < endMs; 0 ≤ startMs; endMs ≤ durationMs семпла — SegmentInvalidRange — ms
  - Минимальная длительность сегмента после правки — 50 ms; максимум — durationMs семпла — SegmentTooShort / SegmentInvalidRange — ms — предел: ≥50 ms
  - kind=word: целевой коридор 80–800 ms (вне коридора сегмент можно принять, но UI помечает «короткий/длинный для слова») — ms — жёсткий отказ только <50 ms
  - kind=phrase: целевой коридор 400–15000 ms — аналогично
  - Обучение: нужно ≥1 VoiceSample и ≥3 accepted Segment И суммарная длительность accepted ≥ 15000 ms — NoAcceptedSegments или DatasetTooSmallForTraining — штуки / ms
  - Статус сегмента pending не участвует в обучении; rejected не участвует — только accepted
  - Нарезка предлагает границы; источник правды для обучения — ручной status=accepted — без принятых сегментов обучение отвергать
  - TTS: непустой ScriptText; модель status=ready — ScriptTextEmpty / ModelNotReady
  - Время везде в ms (целое); sampleRate в Hz; прогресс job в % 0–100 целыми — не смешивать секунды и ms в одном поле
Запреты:
  - Обучать/импортировать как «чужой знаменитый голос» без явного подтверждения человека, что у него есть право на голос — последствие: юридический и этический риск; в продукте — ConfirmVoiceRights перед train/import (флаг согласия)
  - Обещать на экране «100% копия личности» / «идентификация человека» — модель ≠ биометрия; тексты только «озвучка в стиле вашего датасета»
  - Принимать семпл короче 500 ms или длиннее 5 мин в v1 — деградирует нарезку и обучение
  - Скрыто подменять rejected сегменты в train — ломает контроль качества датасета
Подтверждение человека:
  - Перед startTraining и importModel: явное «У меня есть право использовать этот голос в модели» (voiceRightsConfirmed=true в запросе)
  - Принятие сегментов (accepted) — человек подтверждает границы; автонарезка сама по себе не обучает
Не подтверждено:
  - Точные SNR/пороги клиппинга для studio mic (нужны замеры на целевом железе) — не фиксируем dB как факт в v1; оставляем риск в RISKS
  - Оптимальный объём часов речи под конкретный архитектуру сети — зависит от будущего real trainer; сейчас только нижний порог 15 s accepted
Дыры в контракте и текстах:
  - CONTRACT: добавить SampleDurationInvalid, SampleChannelsUnsupported, SegmentTooShort, DatasetTooSmallForTraining; startTraining/importModel требуют voiceRightsConfirmed=true
  - DESIGN Датасет/Модели: не обещать «клон личности»; пустое обучение — текст DatasetTooSmallForTraining; чекбокс прав на голос перед обучением/импортом
  - GLOSSARY: дополнить новые ошибки и термин voiceRightsConfirmed
```
