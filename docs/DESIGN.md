# Design

Платформа v1: **локальное desktop-приложение** (окно студии, не браузерный SaaS).

Визуальное направление: **консоль записи** — прохладный стальной холст, один бирюзовый акцент «звук/действие», плотная продуктовая сетка. Без фиолетового SaaS, без кремово-терракотового editorial, без газетной вёрстки.

Источник сдачи: спецификация ниже + `docs/PRD.md` + `docs/GLOSSARY.md`.

## Цвета: основные и дополнительные

| Роль | Токен | Hex |
|---|---|---|
| Фон окна | `canvas` | `#DCE4EA` |
| Поверхность работы | `surface` | `#F4F7FA` |
| Панель / сайдбар | `panel` | `#CBD6DF` |
| Текст | `ink` | `#15202B` |
| Текст тихий | `mute` | `#5B6B7A` |
| Линия | `line` | `#A8B6C3` |
| Действие | `action` | `#0E7C86` |
| Действие hover | `action-hover` | `#0A636B` |
| Опасность / запись | `danger` | `#B42318` |
| Успех | `success` | `#217A45` |
| Фокус кольцо | `focus` | `#0E7C86` @ 2px, offset 2px |

Контраст: `ink` на `surface` и `canvas` ≥ 7:1. Текст на кнопке действия — `#FFFFFF` на `action`.

## Шрифты

| Роль | Семейство |
|---|---|
| UI / заголовки / кнопки | **IBM Plex Sans** |
| Время, waveform-метки, ID модели, API | **IBM Plex Mono** |

Не использовать Inter, Roboto, Arial, system-ui как основной стек.

## Типографика

Шкала (desktop, fixed rem, ratio ~1.2):

| Роль | Размер / line-height / weight |
|---|---|
| Заголовок окна / экрана | 22 / 28 / 600 |
| Заголовок блока | 16 / 22 / 600 |
| Основной текст | 14 / 20 / 400 |
| Подпись / meta | 12 / 16 / 400 |
| Mono data | 12 / 16 / 500 IBM Plex Mono |

Sentence case. Без ALL-CAPS лейблов и без акцента «одно слово другим цветом» в заголовках.

## Компоненты

- Shell: верхняя полоса приложения (имя Mira + имя модели/датасета) + левый шаг-навигатор пути + основная сцена.
- Primary button: заливка `action`, радиус 6, высота 36, padding 12×16.
- Secondary: прозрачный фон, обводка `line`, тот же размер.
- Danger: заливка `danger` только для уничтожения/остановки записи.
- List row: высота 48, разделитель `line`, hover `surface`→ чуть темнее panel mix.
- Status pill: текст + точка цвета (mute / action / success / danger), радиус 4, не «rounded-full marketing pill cluster».
- Waveform / timeline: mono метки, playhead `action`, сегменты полупрозрачный `action` 20%.

Состояния контролов: default, hover, focus-visible, active, disabled, loading, error.

## Отступы

Шкала: **4, 8, 12, 16, 24, 32, 48**.  
Окно: padding сцены 24. Между блоками 24. Внутри панели 16. Между контролами в ряду 8–12. Сайдбар ширина 220.

## Спецификация экранов

### Экран: Студия
```text
Экран: Студия
Путь: вход в выпуск; обзор следующего шага
Главное действие: Начать с датасета
Состав:
  - шапка — «Mira» + подпись «Studio Path»
  - левый нав — 7 шагов пути; текущий «Студия»
  - центр — одно предложение пути + CTA «Начать с датасета»
  - низ/бок — статус последнего: датасет / модель / API (тихо, не статистическая полоса)
  - UpdateBanner под шапкой приложения (все экраны) — статус обновления из GitHub Releases
Состояния:
  - пусто — нет датасета и модели; живы «Начать с датасета», «Импортировать модель»
  - готово — есть датасет или модель; живы продолжение с последнего незакрытого шага + «Начать с датасета»
  - ошибка — прошлый job упал; текст ошибки + «Открыть лог» + переход к шагу
  - UpdateBanner: idle скрыт; checking «Проверяем обновления…»; available «Доступна версия X»; downloading «Скачиваем… N%»; ready «Обновление готово» + CTA «Перезапустить»; upToDate без баннера; error текст + «Проверить снова»
Сетка и отступы: сцена max-width 720 внутри окна; CTA слева; вертикальный ритм 24; баннер на всю ширину контента, padding 12×16
Тип: заголовок экрана 22/28/600; пояснение 14/20; mono только в статусах ID и версии
Цвет: canvas фон окна; surface центральная зона; action на CTA; баннер ready — success border
Тексты:
  - «Начать с датасета»
  - «Импортировать модель»
  - «Перезапустить»
  - «Проверить обновления»
  - пусто: «Добавьте голос, чтобы собрать модель и озвучку.»
  - ошибка: «Последняя задача не завершилась. Откройте шаг и повторите.»
  - update error: «Не удалось проверить обновления. Проверьте сеть и повторите.»
Движение: смена шага нав — без анимации (часто). Баннер — opacity 180ms ease-out; reduced motion — мгновенно. Прогресс загрузки — смена % без анимации бара каждый тик.
Фокус и подписи: Tab: нав → CTA → secondary; при ready — «Перезапустить» в баннере. aria-live=polite на баннере.
Ремесло: frontend-design; impeccable/product; animate
```

### Экран: Датасет
```text
Экран: Датасет
Путь: запись и импорт VoiceSample в Dataset
Главное действие: Записать семпл
Состав:
  - шапка блока — имя датасета (поле) + счётчик семплов (mono)
  - панель записи — кнопка записи, уровень входа (простая полоска), таймер mono
  - список семплов — имя, длительность, статус
  - secondary — «Импортировать аудио»
Состояния:
  - пусто — список пуст; «Записать семпл», «Импортировать аудио» живы
  - запись — кнопка становится «Остановить запись» (danger); список disabled
  - загрузка — импорт: skeleton строк
  - готово — строки семплов; «К нарезке» жива если ≥1 семпла
  - ошибка SampleImportFailed / запись — баннер + повтор
  - запрет — «К нарезке» disabled без семплов; подпись почему
Состояния строки: hover, selected, missing file
Сетка и отступы: двухколоночно на широком окне — запись 320 / список flex; gap 24
Тип: имя семпла 14/20/500; длительность mono 12/16
Цвет: запись active = danger; уровень входа = action fill
Тексты:
  - «Записать семпл» / «Остановить запись»
  - «Импортировать аудио»
  - «К нарезке»
  - пусто: «Запишите голос или импортируйте файл WAV/FLAC.»
  - SampleImportFailed: «Не удалось импортировать файл. Выберите WAV или FLAC и повторите.»
  - SampleDurationInvalid: «Длительность семпла должна быть от 0,5 с до 5 мин.»
  - SampleChannelsUnsupported: «Поддерживаются только mono или stereo (≤2 канала).»
Движение: пульс точки записи 1s linear infinite opacity 1→0.35 (только во время записи); reduced motion — статичная точка. Добавление строки — без fly-in (часто).
Фокус: имя датасета → Записать → Импорт → список → К нарезке. aria-live на таймере записи.
Ремесло: frontend-design; impeccable/product; animate
```

### Экран: Нарезка
```text
Экран: Нарезка
Путь: автонарезка Segment; правка границ
Главное действие: Запустить нарезку
Состав:
  - выбор семпла
  - timeline/waveform с сегментами (слово/фраза)
  - список сегментов — текст (если есть), start–end mono, принять/отклонить
  - secondary — «Сбросить правки»
Состояния:
  - пусто — нет нарезки; CTA «Запустить нарезку»
  - загрузка — job; waveform skeleton + «Нарезаем…»
  - готово — сегменты; «К моделям» жива
  - ошибка SegmentationFailed — баннер + повтор
  - запрет правки во время job
Сетка: waveform на всю ширину сцены высота 160; список под ним; gap 16
Тип: метки времени mono; подписи сегментов 14/20
Цвет: сегмент fill action @ 20%; playhead action; отклонённый сегмент mute штрих
Тексты:
  - «Запустить нарезку»
  - «Принять» / «Отклонить»
  - «К моделям»
  - SegmentationFailed: «Нарезка не завершилась. Проверьте семпл и запустите снова.»
Движение: playhead — без spring, прямое следование времени. Появление сегментов после job — opacity 160ms ease-out один раз; reduced motion — сразу.
Фокус: семпл → Запустить → сегменты (стрелки) → К моделям. Подписи границ для screen reader: «сегмент N, с X по Y».
Ремесло: frontend-design; impeccable/product; animate
```

### Экран: Модели
```text
Экран: Модели
Путь: обучение VoiceModel; импорт/экспорт ModelPackage
Главное действие: Обучить модель
Состав:
  - список моделей — имя, статус (обучается / готова / ошибка), дата
  - панель выбранной — имя, датасет-источник, «Экспортировать», «Импортировать модель»
  - форма новой — имя + «Обучить модель»
Состояния:
  - пусто — нет моделей; «Обучить модель», «Импортировать модель»
  - загрузка/обучается — status pill action; primary disabled; прогресс текстом %
  - готово — статус success; экспорт жив; «К тексту» жива
  - TrainingFailed / ModelImportFailed — опасный баннер + «Открыть лог»
Состояния: нельзя удалить единственную готовую без confirm danger «Удалить модель»
Сетка: список 280 + деталь; gap 24
Тип: имя 16/22/600; статус 12/16; путь пакета mono
Цвет: status готовится action; готова success; ошибка danger
Тексты:
  - «Обучить модель»
  - «Экспортировать»
  - «Импортировать модель»
  - «Удалить модель»
  - «К тексту»
  - чекбокс обязательный: «У меня есть право использовать этот голос в модели»
  - подпись модели: «Озвучка в стиле вашего датасета» (не «клон личности»)
  - TrainingFailed: «Обучение не завершилось. Откройте лог и запустите снова.»
  - ModelImportFailed: «Пакет модели не открылся. Выберите файл Mira Model Package.»
  - DatasetTooSmallForTraining: «Для обучения нужно ≥3 принятых сегмента и ≥15 с суммарно.»
  - VoiceRightsNotConfirmed: «Подтвердите право использовать этот голос.»
Движение: прогресс — смена числа без анимации бара каждый тик (часто). Смена статуса в pill — color 150ms ease-in-out.
Фокус: список → имя → Обучить → Импорт → Экспорт → К тексту.
Ремесло: frontend-design; impeccable/product; animate
```

### Экран: Текст
```text
Экран: Текст
Путь: ScriptText вручную и через LLM
Главное действие: Сгенерировать текст
Состав:
  - редактор текста (основное поле)
  - secondary ряд — «Сгенерировать текст», «Улучшить текст»
  - подпись лимита / языка тихо
Состояния:
  - пусто — placeholder; «Сгенерировать текст» жива; «К озвучке» disabled
  - загрузка LLM — поле read-only + skeleton/overlay «Пишем…»
  - готово — текст есть; «К озвучке» жива
  - LlmFailed — баннер; поле разблокировано
Сетка: редактор max-width 720; min-height 280; padding 16
Тип: текст редактора 14/22; кнопки 14/20/500
Цвет: focus ring на поле; action на generate
Тексты:
  - «Сгенерировать текст»
  - «Улучшить текст»
  - «К озвучке»
  - placeholder: «Введите текст озвучки или сгенерируйте.»
  - LlmFailed: «LLM не вернул текст. Проверьте связь с моделью и повторите.»
Движение: нет анимации набора в редакторе. Баннер ошибки — 180ms ease-out opacity.
Фокус: редактор → Сгенерировать → Улучшить → К озвучке. label «Текст озвучки».
Ремесло: frontend-design; impeccable/product; animate
```

### Экран: Озвучка
```text
Экран: Озвучка
Путь: TTS → AudioRender превью и сохранение
Главное действие: Озвучить
Состав:
  - выбор VoiceModel (обязательно)
  - превью текста (read-only truncate)
  - плеер результата + «Сохранить аудио»
  - CTA «Озвучить»
Состояния:
  - пусто — нет рендера; Озвучить жива если модель+текст
  - загрузка RenderJob — «Озвучиваем…»; контролы disabled
  - готово — плеер; Сохранить жива
  - TtsFailed — баннер + повтор
  - запрет — нет модели или текста; подпись
Сетка: колонка 560; плеер на всю ширину колонки
Тип: mono длительность; заголовок блока 16/22
Цвет: action CTA; success после сохранения toast
Тексты:
  - «Озвучить»
  - «Сохранить аудио»
  - «К подключению»
  - TtsFailed: «Озвучка не собралась. Выберите модель и повторите.»
  - успех: «Аудио сохранено.»
Движение: появление плеера после job — opacity 180ms ease-out; reduced motion — сразу. Play/pause без bounce.
Фокус: модель → Озвучить → плеер → Сохранить → К подключению. aria-live на статусе job.
Ремесло: frontend-design; impeccable/product; animate
```

### Экран: Подключение
```text
Экран: Подключение
Путь: локальный API/SDK для других проектов
Главное действие: Запустить API
Состав:
  - тумблер/кнопка «Запустить API» / «Остановить API»
  - блок endpoint URL (mono, copy)
  - пример вызова (mono)
  - выбор модели по умолчанию для API
Состояния:
  - пусто/выкл — API остановлен; «Запустить API»
  - готово/вкл — URL + пример; «Остановить API» secondary danger-outline
  - ApiAuthFailed / порт занят — ошибка с действием «Сменить порт»
  - загрузка — старт сервиса
Сетка: одна колонка max 640; code block padding 16; radius 6
Тип: URL и code — IBM Plex Mono 12/18
Цвет: индикатор вкл = success точка; выкл = mute
Тексты:
  - «Запустить API»
  - «Остановить API»
  - «Скопировать URL»
  - «Сменить порт»
  - ApiAuthFailed: «Запрос без доступа отклонён. Проверьте токен в настройках API.»
  - порт: «Порт занят. Выберите другой порт и запустите снова.»
Движение: нет анимации тумблера сверх color 150ms. Copy toast 180ms ease-out.
Фокус: Запустить → Скопировать → модель по умолчанию → Сменить порт.
Ремесло: frontend-design; impeccable/product; animate
```
