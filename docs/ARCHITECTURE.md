# Architecture

## Общая схема (флоу)

1. Человек открывает Mira Studio.
2. Добавляет голос: запись или импорт → датасет.
3. Запускает автонарезку → сегменты (слова/фразы).
4. Обучает голосовую модель → артефакт модели.
5. Пишет или генерирует текст (LLM) → отправляет в TTS.
6. Слушает превью / сохраняет аудио.
7. Экспортирует модель или вызывает локальный API/SDK из другого проекта.

Детали стека и структуры папок — после сдачи бэкенда и DevOps.
