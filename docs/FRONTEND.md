# Frontend — сдача Mira Desktop

```text
Где открыть:
  - Dev UI: http://127.0.0.1:5173 (Vite; proxy /v1 → studio-api :8741)
  - Desktop окно: cd apps/desktop && npm run desktop (нужен запущенный studio-api)
Пройденный путь:
  - Студия загружается, нав из 7 шагов, proxy health/datasets ок
  - Экраны Датасет / Нарезка / Модели / Текст / Озвучка / Подключение открываются без падения
Экраны и состояния:
  - Студия — пусто / готово / ошибка API
  - Датасет — пусто, запись, импорт, ошибка контракта, «К нарезке» disabled без семплов
  - Нарезка — пусто, загрузка job, сегменты, принять/отклонить
  - Модели — пусто, обучение, rights checkbox, импорт/экспорт, статусы
  - Текст — пусто, LLM loading, готово, ошибка
  - Озвучка — запрет без модели/текста, loading, плеер
  - Подключение — API on/off, token, URL, пример curl
Расхождения со спецификацией:
  - Waveform на Нарезке — упрощённые блоки сегментов без playhead-scrubber (достаточно для v1 path)
  - Запись микрофона конвертируется WebM→WAV на клиенте; при экзотическом sampleRate возможен SampleRateUnsupported
Расхождения с контрактом:
  - нет
Как проверить:
  1. Запустить studio-api на :8741
  2. cd apps/desktop && npm install && npm run dev
  3. Открыть http://127.0.0.1:5173 — пройти нав по всем экранам
  4. Импортировать wav ≥0.5с → нарезка → принять сегменты → обучить с чекбоксом прав → текст → озвучка → API
```

Скриншоты: `docs/artifacts/studio_screen.webp`, `dataset_screen.webp`, `models_screen.webp`.
