# Mira — установка на Windows (x64)

Версия: **0.1.0**  
Сборка: unsigned (SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае»).

## Что в папке

| Файл | Назначение |
|------|------------|
| `Mira-Setup-0.1.0-win-x64.exe` | Установщик NSIS: выбор папки, ярлыки на рабочем столе и в меню «Пуск» |
| `Mira-Portable-0.1.0-win-x64.exe` | Портативная сборка: запуск без установки |

## Установка (рекомендуется)

1. Скачайте / скопируйте `Mira-Setup-0.1.0-win-x64.exe`.
2. Запустите установщик.
3. Выберите каталог (по умолчанию `%LOCALAPPDATA%\Programs\Mira`).
4. После установки откройте **Mira** из меню «Пуск» или с рабочего стола.

Для API Studio Path на той же машине нужен запущенный `studio-api` (см. `services/studio-api` и `docs/DEVOPS.md`).

## Портативный запуск

Запустите `Mira-Portable-0.1.0-win-x64.exe` — распаковка во временный каталог и старт UI без записи в Program Files.

## Требования

- Windows 10/11 x64
- Для озвучки на ПК: Python 3.12+, `pip install -e services/studio-api`, ffmpeg в PATH (для edge-tts)

## Примечание по обновлениям

Автообновление через GitHub Releases заработает после публикации tag `mira-v*` и подписанных/опубликованных артефактов в Releases. Локальные файлы из этой папки — ручная установка текущего билда.
